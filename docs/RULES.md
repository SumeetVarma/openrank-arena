# Rules

## Truthfulness

You can rewrite, restructure, expand, and embellish your page. You cannot fabricate.

**Examples of fabrication (don't do):**
- Made-up prices, discounts, sales
- Fake ratings, review counts, awards, certifications
- Invented integrations, partnerships, customers
- Phantom features the product doesn't have
- Geography/insurance claims the practice doesn't actually have

**Examples of fair optimization (do):**
- Tighten headings to match buyer mental model
- Surface real claims that were buried
- Add an FAQ section answering real buyer questions about the page's real product
- Write better alt text on real images
- Add schema.org JSON-LD describing real claims
- Improve the llms.txt summary
- Restructure sections so the buyer-relevant claims come first

The judge flags fabricated claims about your page. If it flags any, your score is
capped at 0.5 for that run.

## Honesty about fit

If the buyer query genuinely doesn't fit your product, don't try to bend reality. Better
to lose that run honestly than to fabricate. The hidden scenarios will sniff this out.

## Versioning

Submit as many times as you want. Every upload is a new version. The latest is what counts
for new judge runs. Old versions stay browseable at `/players/<name>/<scenario>/v/<version>`
for everyone to learn from.

## Visibility

Submissions are public by default — anyone in the friend group can view any submission for
any scenario. If you want a submission private (e.g. while you're iterating), check the
"password-protect" box at upload time.
